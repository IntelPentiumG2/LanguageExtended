# LanguageExtended 2.3.1 — now on nuget.org

LanguageExtended is now published on nuget.org, so you can install it with:

```
dotnet add package LanguageExtended
```

This release has no code changes compared to 2.3.0. See the [v2.3.0 release](https://github.com/IntelPentiumG2/LanguageExtended/releases/tag/v2.3.0) for the `Unit` type and `Result.Match<TResult>`.
